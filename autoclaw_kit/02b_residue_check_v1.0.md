# 知识卡片 v1.0 · 残留文本专项检测规范（autoclaw 端必读）

> **目的**：在 autoclaw 端产卡时**直接避免** LLM repetition / 模板化文本污染。本文件是 `02_spec_card_v1.0.md` 的**专项补丁**。
> **触发原因**：本轮实测 173 套共 1010 张卡 back_detail 末尾污染（"补充说明：本考点在近三年上海等级考中..."），全量清洗后才堵住。
> **面向对象**：autoclaw 端知识卡片制作人员（含 LLM prompt 模板维护者）。

---

## 1. 什么是"残留文本"？

**定义**：LLM 在生成内容时**重复或模板化**添加的冗余文本，特征：
- 在段落末尾突然出现
- 与前后文**无逻辑承接**（不像自然续写）
- 模式高度**可枚举**（不是 LLM 自由发挥的产物）
- 删除后**不影响信息完整性**

**典型表现**：
- back_detail 末尾："补充说明：本考点在近三年..."（已实测 1010 张）
- 卡片中间突然出现："记住：考试常考..."、"重点：这是核心..."、"总之：..."、"综上所述：..."
- 任何"模板化开场白"+"重复套话"组合

```markdown
【反残留规则 · 硬约束】
1. 禁止在 back_detail 末尾（或任意位置）添加以下模板：

   - "重点：..." / "记住：..." / "总之：..." / "综上所述：..."

4. 输出前自检：删除所有符合上述模式的字符串后再交付。
```

## 4. ERR-12 规则实现规范（PC 端校验）

### 4.1 规则定义

```
规则 ID: ERR-12
规则名: back_detail 残留模板
触发: back_detail 字段值匹配以下任一 regex
等级: ERR（直接拒绝入库）
```

### 4.2 必备 regex（Python re）

```python
import re

RESIDUE_PATTERNS = [
    # 模式 A
    re.compile(r'补充说明[：:].*?本考点在近三年上海等级考中属高频内容[，,].*?务必结合案例与辨析要点。'),
    # 模式 B
    re.compile(r'补充说明[：:].*?本考点在近三年上海等级考中属高频内容[，,].*?务必结合史实与辨析要点。'),
    # 模式 C
    re.compile(r'补充说明[：:].*?本考点在近三年上海等级考中属高频内容[，,].*?务必结合史实与辨析要点，做到以史实立论、以方法释史。'),
    # 模式 C' 尾巴
    re.compile(r'这一历史考点在专题框架中占有重要位置。'),
    # 通用套话（防御性）
    re.compile(r'^补充说明[：:](?:本考点|本节|本主题).*?[。]'),  # 任意"补充说明：..." 开头
]

def check_residue(text: str) -> list[str]:
    """返回所有命中的残留模式描述"""
    issues = []
    for pat in RESIDUE_PATTERNS:
        m = pat.search(text)
        if m:
            issues.append(f'[{pat.pattern[:30]}...] 命中: {m.group()[:50]}')
    return issues
```

### 4.3 集成到 `_validate_cards.py`

```python
# 在 check_card() 末尾加：
for field in ['back_core', 'back_detail']:
    if field in card and isinstance(card[field], str):
        issues = check_residue(card[field])
        for iss in issues:
            add_err(f"[ERR-12 残留] {where} {field} {iss}")
```
